## 如何更新

和往常一样，你可以使用以下命令之一更新你的机器人：

### docker-compose

```bash
docker-compose pull
docker-compose up -d
```

### 通过 setup 脚本安装

``` bash
# 停用 venv 并运行 
./setup.sh --update
```

### 裸机原生安装

``` bash
git pull
pip install -U -r requirements.txt
```
