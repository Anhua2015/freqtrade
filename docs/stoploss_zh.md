# 止损

`stoploss` 配置参数是应触发卖出的亏损比率。
例如，值 `-0.10` 将在给定交易的利润低于 -10% 时立即卖出。此参数是可选的。
止损计算包含手续费，因此 -10% 的止损精确设置在入场点以下 10% 的位置。

大多数策略文件已经包含了最优的 `stoploss` 值。

!!! Info
    本文中提到的所有止损属性都可以在策略或配置中设置。
    <ins>配置值将覆盖策略值。</ins>

## 交易所止损 / Freqtrade 止损

这些止损模式可以是*在交易所*或*在交易所外*。

这些模式可以用以下值进行配置：

``` python
    'emergency_exit': 'market',
    'stoploss_on_exchange': False
    'stoploss_on_exchange_interval': 60,
    'stoploss_on_exchange_limit_ratio': 0.99
```

交易所止损仅支持以下交易所，且并非所有交易所都同时支持止损限价和止损市价。
如果只有一种模式可用，订单类型将被忽略。

??? info "支持的交易所和止损类型"

    --8<-- "includes/exchange-features.md"

!!! Note "止损过紧"
    使用交易所止损时不要设置过低/过紧的止损值！
    如果设置得过低/过紧，订单无法成交的风险会更大，止损将不起作用。

!!! Warning "止损过松"
    使用交易所止损并设置过宽的止损（例如 -1）可能会因交易所限制而无法在交易所下达止损订单。
    在这种情况下，机器人将回退到使用 `emergency_exit` 订单类型下达市价单，因为下达止损订单失败。
    Freqtrade 目前没有实现限制来避免这种情况，因此请确保你的止损值在交易所的合理范围内，或禁用交易所止损。

### 交易所止损使用哪种订单类型？

交易所止损使用的订单类型由 `stoploss` 值和交易所能力决定。
如果你选择的交易所同时支持止损限价和止损市价订单，则 `stoploss` 值将决定交易所止损使用哪种订单类型。
如果你的交易所仅支持两种订单类型中的一种，你必须相应地配置你的 `stoploss` 值，否则机器人将无法启动。

### 我应该为交易所止损使用哪种订单类型？

如果我们将两种止损订单类型翻译成人话——它们大概是这样的：

* **stoploss-market** → "当止损触发时，无论什么价格，立刻让我出场"。
* **stoploss-limit** → "当止损触发时，在止损价格下方 x% 处下一个限价单。最坏情况下我接受 'stoploss + 1%' 的亏损——但如果价格继续下跌——我接受等待价格回落到我这里，可能导致比 'stoploss + 1%' 更大的亏损。"

因此，我们建议尽可能使用止损市价订单，因为止损的主要目的是在市场暴跌时让你离场，在这种情况下，你会希望以最佳可用价格立即退出仓位，而不是冒着限价单无法成交并可能造成更大亏损的风险。
最终选择权在于你，但请了解使用止损限价单的风险，尤其是在波动性市场中。

### stoploss_on_exchange 和 stoploss_on_exchange_limit_ratio

启用或禁用交易所止损。
如果止损*在交易所*，意味着在买入订单成交后立即在交易所下达一个止损限价单。这将保护你免受市场突然暴跌的影响，因为订单执行完全在交易所内进行，没有潜在的网络开销。

如果 `stoploss_on_exchange` 使用限价单，交易所需要 2 个价格，stoploss_price 和限价。
`stoploss` 定义了限价单被放置的止损价格——限价应略低于此。
如果交易所同时支持限价和市价止损订单，则 `stoploss` 的值将用于确定止损类型。

计算示例：我们在 100$ 买入资产。
止损价为 95$，则限价将为 `95 * 0.99 = 94.05$`——因此限价单成交可发生在 95$ 和 94.05$ 之间。

例如，假设止损在交易所，且启用了跟踪止损，市场正在上涨，则机器人自动取消前一个止损订单并下一个新的止损订单，止损值高于前一个止损订单。

!!! Note
    如果启用了 `stoploss_on_exchange` 且止损在交易所被手动取消，则机器人将创建新的止损订单。

### stoploss_on_exchange_interval

对于交易所止损，还有另一个参数 `stoploss_on_exchange_interval`。这配置了机器人检查止损并在必要时更新止损的间隔秒数。
机器人无法每 5 秒（每次迭代）执行一次此操作，否则会被交易所封禁。
因此，此参数将告诉机器人应多久更新一次止损订单。默认值为 60（1 分钟）。
如果你意外取消了交易所的止损订单，同样的逻辑将重新在交易所下达止损订单。

### stoploss_price_type

!!! Warning "仅适用于合约"
    `stoploss_price_type` 仅适用于合约市场（在可用的交易所上）。
    Freqtrade 将在启动时验证此设置，如果为你的交易所选择了无效设置，将无法启动。
    支持的价格类型因交易所而异。请与你的交易所确认其支持哪些价格类型。
    在现货市场中，此设置被忽略且不进行验证，因为大多数交易所的现货市场仅支持一种止损订单价格类型。

合约市场上的交易所止损可按不同的价格类型触发。
这些价格在交易所术语中的命名通常有所不同，但通常围绕 "last"（或 "contract price"）、"mark" 和 "index"。

此设置的可接受值为 `"last"`、`"mark"` 和 `"index"`——freqtrade 将自动将其转换为相应的 API 类型，并相应地下达[交易所止损](#stoploss_on_exchange-and-stoploss_on_exchange_limit_ratio)订单。

### force_exit

`force_exit` 是一个可选值，默认与 `exit` 相同，在从 Telegram 或 Rest API 发送 `/forceexit` 命令时使用。

### force_entry

`force_entry` 是一个可选值，默认与 `entry` 相同，在从 Telegram 或 Rest API 发送 `/forceentry` 命令时使用。

### emergency_exit

`emergency_exit` 是一个可选值，默认为 `market`，在创建交易所止损订单失败时使用。
以下是默认值，如果未在策略或配置文件中更改则使用。

策略文件中的示例：

``` python
order_types = {
    "entry": "limit",
    "exit": "limit",
    "emergency_exit": "market",
    "stoploss": "market",
    "stoploss_on_exchange": True,
    "stoploss_on_exchange_interval": 60,
    "stoploss_on_exchange_limit_ratio": 0.99
}
```

## 止损类型

目前机器人包含以下止损支持模式：

1. 静态止损。
2. 跟踪止损。
3. 跟踪止损，自定义正向亏损。
4. 仅在交易达到某个偏移后才启用跟踪止损。
5. [自定义止损函数](strategy-callbacks.md#custom-stoploss)

### 静态止损

这非常简单，你定义 x 的止损（作为价格的比率，即 x * 100% 的价格）。一旦亏损超过定义的亏损，这将尝试卖出资产。

止损示例：

``` python
    stoploss = -0.10
```

例如，简化计算：

* 机器人以 100$ 的价格买入资产
* 止损定义为 -10%
* 一旦资产跌至 90$ 以下，止损将触发

### 跟踪止损

初始值为 `stoploss`，就像你定义静态止损一样。
要启用跟踪止损：

``` python
    stoploss = -0.10
    trailing_stop = True
```

这将激活一个算法，每当你的资产价格上涨时，自动将止损上移。

例如，简化计算：

* 机器人以 100$ 的价格买入资产
* 止损定义为 -10%
* 一旦资产跌至 90$ 以下，止损将触发
* 假设资产现在涨至 102$
* 止损现在将是 102$ 的 -10% = 91.8$
* 现在资产价值跌至 101$，止损仍为 91.8$ 并将在 91.8$ 触发。

总结：止损将被调整为始终是历史最高观测价格的 -10%。

### 跟踪止损，不同的正向亏损

你也可以在处于亏损（买入 - 手续费）时使用默认止损，但一旦达到正向结果（或你定义的偏移），系统将使用新的止损，值不同。
例如，你的默认止损是 -10%，但一旦达到盈利（例如 0.1%），将使用不同的跟踪止损。

!!! Note
    如果你只想在盈亏平衡或盈利时才更改止损（大多数用户想要的），请参考下一节[启用偏移](#trailing-stop-loss-only-once-the-trade-has-reached-a-certain-offset)。

两个值都需要将 `trailing_stop` 设置为 true 且 `trailing_stop_positive` 有值。

``` python
    stoploss = -0.10
    trailing_stop = True
    trailing_stop_positive = 0.02
    trailing_stop_positive_offset = 0.0
    trailing_only_offset_is_reached = False  # 默认 - 此示例不需要
```

例如，简化计算：

* 机器人以 100$ 的价格买入资产
* 止损定义为 -10%
* 一旦资产跌至 90$ 以下，止损将触发
* 假设资产现在涨至 102$
* 止损现在将是 102$ 的 -2% = 99.96$（99.96$ 止损将被锁定，并将跟随资产价格增量以 -2% 移动）
* 现在资产价值跌至 101$，止损仍为 99.96$ 并将在 99.96$ 触发

0.02 将转换为 -2% 的止损。
在此之前，`stoploss` 用于跟踪止损。

!!! Tip "使用偏移来更改你的止损"
    通过将 `trailing_stop_positive_offset` 设置为高于 `trailing_stop_positive`，确保你的新跟踪止损将处于盈利状态。这样你的第一个新止损值将已经锁定利润。

    简化计算示例：

    ``` python
        stoploss = -0.10
        trailing_stop = True
        trailing_stop_positive = 0.02
        trailing_stop_positive_offset = 0.03
    ```

    * 机器人以 100$ 的价格买入资产
    * 止损定义为 -10%，因此一旦资产跌至 90$ 以下，止损将触发
    * 假设资产现在涨至 102$
    * 止损现在将位于 91.8$——历史最高观测价格的 -10%
    * 假设资产现在涨至 103.5$（高于配置的偏移）
    * 止损现在将是 103.5$ 的 -2% = 101.43$
    * 现在资产价值跌至 102$，止损仍为 101.43$，一旦价格跌破 101.43$ 将触发

### 仅在交易达到某个偏移后才启用跟踪止损

你也可以保持静态止损直到达到偏移，然后当市场转向时跟踪交易以获取利润。

如果 `trailing_only_offset_is_reached = True`，则跟踪止损仅在达到偏移后才激活。在此之前，止损保持在配置的 `stoploss` 且不跟踪。
将此值保留为 `trailing_only_offset_is_reached=False` 将允许跟踪止损在资产价格上涨超过初始入场价后立即开始跟踪。

此选项可与 `trailing_stop_positive` 一起使用或不使用，但使用 `trailing_stop_positive_offset` 作为偏移。

配置（偏移是买入价 + 3%）：

``` python
    stoploss = -0.10
    trailing_stop = True
    trailing_stop_positive = 0.02
    trailing_stop_positive_offset = 0.03
    trailing_only_offset_is_reached = True
```

例如，简化计算：

* 机器人以 100$ 的价格买入资产
* 止损定义为 -10%
* 一旦资产跌至 90$ 以下，止损将触发
* 除非资产涨至或超过配置的偏移，止损将保持在 90$
* 假设资产现在涨至 103$（我们配置偏移的位置）
* 止损现在将是 103$ 的 -2% = 100.94$
* 现在资产价值跌至 101$，止损仍为 100.94$ 并将在 100.94$ 触发

!!! Tip
    确保此值（`trailing_stop_positive_offset`）低于最小 ROI，否则最小 ROI 将先触发并卖出交易。

## 止损与杠杆

止损应被理解为"此交易的风险"——因此 100$ 交易上 10% 的止损意味着你愿意在此交易上亏损 10$（10%）——这将在价格下跌 10% 时触发。

使用杠杆时，适用相同的原则——止损定义交易的风险（你愿意亏损的金额）。

因此，10x 交易上的 10% 止损将在 1% 的价格变动时触发。
如果你的投入金额（自有资金）是 100$——此交易在 10x 杠杆下将是 1000$。
如果价格变动 1%——你亏损了 10$ 的自有资金——因此止损将在这种情况下触发。

确保你意识到这一点，避免使用过紧的止损（在 10x 杠杆下，10% 的风险可能太小，不足以让交易"喘息"一下）。

## 更改未平仓交易的止损

未平仓交易的止损可以通过更改配置或策略中的值并使用 `/reload_config` 命令来更改（或者完全停止并重启机器人也可以）。

新的止损值将应用于未平仓交易（并生成相应的日志消息）。

### 限制

如果 `trailing_stop` 已启用且止损已经被调整，则无法更改止损值。
