# 杠杆交易

!!! Note "一个账户多个机器人"
    你不能在同一个账户上使用杠杆运行 2 个机器人。对于杠杆/保证金交易，freqtrade 假定它是账户的唯一用户，所有清算水平都基于此假设计算。

!!! Danger "杠杆交易风险极高"
    不要使用杠杆 > 1 来运行尚未在现货市场实盘中显示正收益的策略。检查你策略的止损。使用 2 倍杠杆时，0.5（50%）的止损太低了，这些交易会在达到该止损之前被清算。
    我们对因使用本软件或此模式而可能发生的任何损失不承担任何责任。

    只有在你了解 freqtrade（和你的策略）如何工作的情况下，才使用高级交易模式。
    另外，永远不要冒超出你承受能力的风险。

如果你已有策略，请阅读[策略迁移指南](strategy_migration.md#strategy-migration-between-v2-and-v3)，将你的策略从 freqtrade v2 策略迁移到可以开空头和交易合约的 v3 策略。

## 做空

当 `trading_mode` 设置为 `spot` 时无法做空。要开空头，`trading_mode` 必须设置为 `margin`（当前不可用）或 [`futures`](#futures)，且 [`margin_mode`](#margin-mode) 设置为 [`cross`](#cross-margin-mode) 或 [`isolated`](#isolated-margin-mode)。

策略要做空，策略类必须设置类变量 `can_short = True`。

请阅读[策略定制](strategy-customization.md#entry-signal-rules)了解如何设置信号以进入和退出空头交易。

## 理解 `trading_mode`

可能的值为：`spot`（默认）、`margin`（*当前不可用*）或 `futures`。

### 现货（Spot）

常规交易模式（低风险）

- 仅多头交易（无空头交易）。
- 无杠杆。
- 无清算。
- 盈亏等于资产价值的变化（减去交易手续费）。

### 杠杆交易模式

使用杠杆时，交易者从交易所借入资本。借入的资本必须全额偿还给交易所（可能含利息），交易者保留任何利润，或承担使用借入资本进行交易产生的任何损失。

由于资本必须始终偿还，当杠杆账户中资产的总价值下降到某个点（总损失价值低于交易者实际拥有在杠杆账户中的抵押品价值的点）时，交易所将**清算**（强制卖出交易者的资产）使用借入资本进行的交易，以确保交易者有足够的资本将借入资产偿还给交易所。交易所还将收取**清算费**，增加交易者的损失。

因此，**如果你不完全了解自己在做什么，请勿使用杠杆进行交易。杠杆交易风险极高，可能导致你的资产价值迅速降至 0，且没有机会再次增值。**

#### 保证金（Margin，当前不可用）

交易发生在现货市场，但交易所以等于所选杠杆的金额借给你货币。你将借给你的金额连同利息偿还给交易所，你的盈亏乘以指定的杠杆。

#### 合约（Futures）

永续合约（也称为永续期货）是以与其基础资产紧密关联的价格交易的合约（例如）。你不是交易实际资产，而是交易衍生合约。永续合约可以无限期持续，与期货或期权合约不同。

除了期货合约价格变动带来的盈亏外，交易者还会交换_资金费率_，这是由期货合约与基础资产价格之间的差异得出的盈亏。期货合约与基础资产之间的价格差异因交易所而异。

要在合约市场中交易，你需要将 `trading_mode` 设置为 "futures"。
你还需要选择"保证金模式"（下文说明）。

``` json
"trading_mode": "futures",
"margin_mode": "isolated"
```

##### 交易对命名

Freqtrade 遵循 [ccxt 合约命名约定](https://docs.ccxt.com/#/README?id=perpetual-swap-perpetual-future)。
合约交易对的命名格式为 `基础货币/计价货币:结算货币`（例如 `ETH/USDT:USDT`）。

### 保证金模式

除了 `trading_mode`——你还需要配置你的 `margin_mode`。
虽然 freqtrade 目前仅支持一种保证金模式，但将来会改变，现在配置好你就能为将来的更新做好准备。

可能的值为：`isolated` 或 `cross`。

#### 逐仓保证金模式（Isolated）

每个市场（交易对）在独立账户中保持抵押品

``` json
"margin_mode": "isolated"
```

#### 全仓保证金模式（Cross）

一个账户用于在多个市场（交易对）之间共享抵押品。在需要时从总账户余额中提取保证金以避免清算。

``` json
"margin_mode": "cross"
```

请阅读[交易所特定说明](exchanges.md)了解支持此模式的交易所及其差异。

!!! Warning "清算风险增加"
    全仓保证金模式增加了全额账户清算的风险，因为所有交易共享相同的抵押品。
    一笔交易的亏损可能影响其他交易的清算价格。
    此外，在模拟或回测模式下，跨仓位影响可能无法完全模拟。

## 设置杠杆倍数

不同的策略和风险偏好需要不同的杠杆水平。
虽然你可以配置一个静态杠杆值——freqtrade 为你提供了通过[策略杠杆回调](strategy-callbacks.md#leverage-callback)进行调整的灵活性——这允许你按交易对使用不同的杠杆，或基于其他有利于策略结果的因素进行调整。

如果未实现，杠杆默认值为 1x（无杠杆）。

!!! Warning
    更高杠杆也等于更高风险——请确保你完全理解使用杠杆的含义！

## 理解 `liquidation_buffer`

*默认值为 `0.05`*

一个比率，指定在清算价格和止损之间放置多大的安全垫，以防止仓位达到清算价格。
此人工清算价格的计算方式为：

`freqtrade_liquidation_price = liquidation_price ± (abs(open_rate - liquidation_price) * liquidation_buffer)`

- `±` = 多头使用 `+`
- `±` = 空头使用 `-`

可能的值为 0.0 到 0.99 之间的任何浮点数。

**例如：** 如果交易以 10 币/USDT 的价格入场，该笔交易的清算价格为 8 币/USDT，则 `liquidation_buffer` 设置为 `0.05` 时，此交易的最小止损为 $8 + ((10 - 8) * 0.05) = 8 + 0.1 = 8.1$

!!! Danger "`liquidation_buffer` 为 0.0 或较低的 `liquidation_buffer` 可能导致清算和清算费用"
    目前 Freqtrade 能够计算清算价格，但不计算清算费用。将你的 `liquidation_buffer` 设置为 0.0 或使用较低的 `liquidation_buffer` 可能导致你的仓位被清算。Freqtrade 不跟踪清算费用，因此清算将导致机器人的盈亏结果不准确。如果你使用较低的 `liquidation_buffer`，建议在交易所支持的情况下使用 `stoploss_on_exchange`。

## 不可用的资金费率

对于合约数据，交易所通常提供合约 K 线、标记价格和资金费率。然而，常见的情况是 K 线和标记价格可能可用，但资金费率不可用。这可能会影响回测时间范围，即你可能只能测试最近的时间范围而无法测试更早的时间范围，会收到 `No data found. Terminating.` 错误。为了解决这个问题，请按照 [configuration.md](configuration.md) 中列出的方式添加 `futures_funding_rate` 配置选项，建议将其设置为 `0`，除非你知道你的交易对、交易所和时间范围的特定资金费率。将其设置为 `0` 以外的任何值都会对你的策略内的利润计算产生重大影响，例如在 `custom_exit`、`custom_stoploss` 等函数中。

!!! Warning "这意味着你的回测将不准确。"
    这不会覆盖交易所可用的资金费率，但请记住，设置一个错误的资金费率意味着在资金费率不可用的历史时间范围内，回测结果将不准确。

### 开发者

#### 保证金模式

对于空头，支付 `borrowed` 货币利息费的货币在平仓交易的同时购买（这意味着做空平仓交易中购买的数量大于做空开仓交易中出售的数量）。

对于多头，支付 `borrowed` 货币利息费的货币已由用户拥有，无需购买。利息从交易的 `close_value` 中扣除。

所有费用都包含在交易期间的 `current_profit` 计算中。

#### 合约模式

资金费会被加到交易总金额中或从中扣除。
